## 💡 Sobre o Projeto

Este é um portfólio de página única (Single Page Application) com um visual limpo, moderno e totalmente responsivo (funciona super bem no celular!). A ideia principal aqui foi criar algo direto ao ponto, onde o foco está nos projetos e nas soluções que eu consigo entregar.

## 🛠️ O que tem debaixo do capô?

Eu escolhi tecnologias que não só dominam o mercado, mas com as quais eu me divirto muito trabalhando:

*   **React:** Para criar a interface e os componentes de forma modular e eficiente.

## 💻 Como rodar este projeto na sua máquina

Se você quiser clonar este repositório e dar uma olhada no código rodando ao vivo, é super simples. Você só precisa ter o **Node.js** instalado na sua máquina.

1. Faça o clone do repositório:
```bash
git clone https://github.com/Ronisank/seu-repositorio-do-portfolio.git
```

2. Entre na pasta do projeto:
```bash
cd seu-repositorio-do-portfolio
```

3. Instale as dependências mágicas:
```bash
npm install
```

4. Rode o servidor local:
```bash
npm run dev
```

5. Abra o seu navegador e acesse o link que vai aparecer no terminal (geralmente é `http://localhost:5173`).
